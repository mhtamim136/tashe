# TaShe Cloud

TaShe Cloud is a no-server personal cloud storage web application. The static frontend runs on GitHub Pages, and every Google Drive operation is brokered by a Google Apps Script web app.

## Architecture

- `Code.gs` is the production Apps Script REST API for the Drive folder `1IRiIh1MOfjJkGAjlj-ig2YD0QBn0pe29`.
- `index.html`, `style.css`, `script.js`, `api.js`, `ui.js`, `utils.js`, and `config.js` are the GitHub Pages frontend.
- Password protection is implemented in Apps Script with salted SHA-256 hashes in Script Properties because Google Drive does not support folder passwords.
- Download and preview links are generated by Apps Script. When necessary, the API sets link-readable Drive permissions because Apps Script cannot act as a high-throughput binary streaming server.

## Deploy

1. Create a Google Apps Script project.
2. Paste the full contents of `Code.gs`.
3. Deploy as a Web App with **Execute as me** and **Anyone** access.
4. Open the GitHub Pages site. The frontend is preconfigured to call the deployed Web App URL: `https://script.google.com/macros/s/AKfycbyVGVKZVepAp0cnHh3FULh-eIv7LrO4S7pouA-tvPQc82DbVBVWJFQW_MwlJruoTLg4/exec`.

## Features

- Browse root and nested folders.
- Upload multiple files with drag-and-drop progress, speed, and remaining time.
- Create unlimited-depth folders.
- Optional folder passwords and a special `Secure` folder passworded with `1663136`.
- Preview supported media/PDF/text files and download others.
- Generate website share links without exposing Google credentials.
- Search, sort, grid/list views, dark mode, responsive File Explorer-inspired UI.
- No delete or rename API is provided.
